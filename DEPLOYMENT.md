AI International Domain Center — GitHub Pages preparation

Deployment type
- This repository is a static HTML/CSS/JavaScript PWA.
- GitHub Pages is suitable for the public website and PWA shell.
- There is no build system or backend in the repository.
- The GitHub Actions workflow deploy-pages.yml is ready for the repository root.

Static-hosting capabilities
- Public homepage
- Static project studio
- Static admin interface shell
- PWA manifest and service worker
- Local demos and browser-only interactions
- Responsive navigation and install prompt

Backend-required capabilities
- Secure admin authentication and roles
- Database/customer accounts
- Domain registrar and DNS operations
- Payments and refunds
- AI provider calls
- Email and notifications
- Backups and audit storage
- Hosting/publishing and real domain connection

Important deployment fact
- No live public URL is claimed until GitHub Pages is enabled and a workflow run succeeds.
- The project Pages URL must be added in GitHub repository Settings > Pages > Build and deployment > GitHub Actions.
- A custom domain requires separate DNS verification and HTTPS configuration.

Android installation after deployment
1. Open Chrome on Android.
2. Visit the verified HTTPS GitHub Pages URL.
3. Tap the public Install App button if Chrome offers it.
4. Otherwise tap Chrome's three-dot menu at the top-right.
5. Tap Add to Home screen or Install app.
6. Confirm the AI International Domain Center name and install.
7. Open the app from the Android home screen and confirm it starts without the normal Chrome address bar.

APK status
- No native APK exists.
- Installation through Chrome is a PWA installation, not an APK download.
